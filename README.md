# arousal-response-variation
Codes for the (at the time of writing this) upcoming paper "Cardiovascular arousal response strength is related to obstructive sleep apnea severity, impaired vigilance, and sleep depth", by Mieli Luukinen _et al._

Parts of the codes are reused from [an earlier paper](https://doi.org/10.1109/JTEHM.2024.3349916).

Dependencies (version numbers refer to the versions I used. Newer or older may also work.):
* Python (3.9.15)
* JupyterLab (3.0.16)
* NumPy (1.23.5)
* Matplotlib (3.3.4)
* SciPy (1.9.3)
* tqdm (4.59.0)
* openpyxl (3.0.9)
* pandas (1.5.2)
